# Підслухано у Ліцеї 8

Клікабельний макет шкільної соцмережі у стилі Threads / Twitter.
Без бази даних: усі дані лежать у `js/data.js`, а зміни (лайки, нові дописи,
відповіді) живуть до перезавантаження сторінки.

## Як запустити
Просто відкрийте `index.html` у браузері (подвійний клік). Сервер не потрібен.

## Структура
- `index.html` — каркас сторінки
- `css/style.css` — усі стилі, світла й темна теми, адаптив під телефон
- `js/data.js` — тестові користувачі, дописи, сповіщення, правила
- `js/app.js` — роутер (`#/feed`, `#/post/p2`, `#/profile` …), рендер і обробка кліків

## Що можна клікати
- Вхід (Google / гість) → стрічка
- Вкладки «Для вас / Анонімні / Підписки» і фільтр за темами
- Лайк, поширення, «надіслати» (копіює посилання), меню ⋯ (приховати, поскаржитися, видалити свій)
- Опитування з голосуванням
- Сторінка допису з відповідями, можна відповісти (зокрема анонімно)
- Новий допис: тема, анонімність, опитування; анонімний іде «на модерацію» і через 6 с схвалюється
- Пошук по дописах і людях, тренди
- Сповіщення, «позначити все прочитаним»
- Свій профіль (редагування) і чужі профілі (підписка)
- Правила спільноти, світла/темна тема

## Що далі (коли буде бекенд)
Замінити масиви в `data.js` на запити до API (наприклад, Laravel), додати
справжню авторизацію через шкільні Google-акаунти та панель модератора.
